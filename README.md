## Configuration

Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json
{
  "mcpServers": {
    "api-tester-ai-mcp": {
      "command": "uvx",
      "args": ["api-tester-ai-mcp"]
    }
  }
}
```

Or: `pip install api-tester-ai-mcp` then run the `api-tester-ai-mcp` command (stdio transport).
